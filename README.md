CYBER INCIDENT RESPONSE SYSTEM

Project Overview

The Cyber Incident Response System is a Java-based mini project that helps organize cybersecurity incidents according to their severity.

Features

1. Add cybersecurity incidents.
2. Prioritize incidents using a PriorityQueue.
3. Process the highest-priority incident first.
4. Record response actions using a Stack.
5. Undo the most recent response action.
6. Reset the system for new testing.

Data Structures Used

PriorityQueue: Used to organize incidents according to severity: Critical, High, Medium, and Low.

Stack: Used to store response actions and support the undo feature.

Technologies Used

Java, HTML, CSS, JavaScript, and Java HTTP Server.
